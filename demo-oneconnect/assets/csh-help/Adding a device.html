Adding a device

Requirements for OneConnect Devices

To be onboarded by OneConnect, a device must meet these requirements:

  • The device must be factory clean.
  • The device must be able to connect to a correctly configured DHCP server.
  • The device must have an IDevID X.509 certificate installed, which is typically part of the device manufacturing process. The certificate must match the device’s serial number.
  • The device must not have autoboot configured on external media (USB or SD card).
  • The device must not have Autonomous Management Framework™ (AMF) auto recovery active.

Add a Device for a Customer

PartnerAdmins and PartnerUsers can add a new device for a Customer to OneConnect. While initially setting up a new device, you can upload a bootstrap configuration file as described in this topic or later as described in Set Up Bootstrapping.

To add a device for a Customer:

  1. Click Customer Management in the left pane and in the table that appears, click a customer name, for example, Customer One.
  2. In the customer page that appears, click + New Device in the upper right corner.
    The New Device dialog will display.
  3. Enter the device’s details, and click Save.
  4. Back in the customer page, click the Devices tab and in the table that appears, verify that the new device was added.
