Adding and allocating licenses

Add New Device Licenses

Before you begin this task:

  • Check with the Allied Telesis Administrator to ensure that they have not already added the new licenses to OneConnect.
  • If the licenses still need to be added, make sure that you have the license key on hand.

OneConnect supports device licenses for 1, 10, 100 or 1,000 devices for a period of 1 year. Once they have the license key, a PartnerAdmin can add the new licenses to OneConnect.

To add one or more new device licenses to OneConnect:

  1. In the left pane, click Customer Management.
    The Customers page will display.
  2. In the Customers page, click Add/Extend Licenses in the upper right corner.
    The Add/Extend Licenses dialog appears.
  3. In the dialog, select Add Devices, enter the license key, and click Save.
  4. Back in the Customers page, check the Total Device Licenses and License Expiry widgets to verify that the license details are properly reflected.

Allocate Device Licenses to a Customer

Before you allocate device licenses to the customers, make sure that:

  • The licenses were added to OneConnect as described in Add New Device Licenses.
  • There are enough licenses for each customer. If more licenses are needed, contact your Allied Telesis representative.

A PartnerAdmin can allocate device licenses to each Customer that the Partner supports. For example, if a license supports 100 devices for 1 year, the PartnerAdmin can allocate 20 device licenses to each of the four Customers that the Partner supports and reserve 20 licenses for future use.

Note: The number of device licenses allocated to a Customer represents the maximum number of devices that can be added for the Customer.
  1. In the left pane, click Customer Management.
    The Customers page will display.
  2. In the table in the Customers page, click the Actions icon associated with a customer, and from the drop-down list that appears, select Allocate Device Licenses.
    The Allocate Device Licenses dialog will appear.
  3. In the dialog, enter the number of licenses, and click Save.
  4. Back in the Customers page, verify that the newly allocated device licenses count appears in the table.
  5. Repeat this procedure for each customer to which you want to allocate device licenses.

Add a License to a Device

A PartnerAdmin or PartnerUser can add a license to a Customer’s device.

By default, you can add a license by specifying a license key. Alternatively, you can upload a file containing the license information.

To add a license to a device:

  1. Click Customer Management in the left pane and in the Customers table that appears, click a customer name, for example, Customer One.
    The customer page will appear.
  2. In the customer page, click the Devices tab.
    In the Devices table, click the device to which you want to add a license.
  3. In the device page that appears, click the Bootstrap Licenses tab, and above and to the right of the table that appears, click + New Device License.
    The New Device License dialog will open.
  4. For License Type, select key or file.
    1. If you selected key, enter the License Name and License Key.
    2. If you selected file, click Upload File and navigate to the file.
  5. Click Save.
  6. Back in the Bootstrap Licenses tab, verify that the newly added license appears in the table.
