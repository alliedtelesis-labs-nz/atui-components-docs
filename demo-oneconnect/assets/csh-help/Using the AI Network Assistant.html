Using the AI Network Assistant

AI Network Assistant

The responses from the AI Network Assistant are initially based on the source information included with the assistant. However, the scope of the responses will increase as the assistant learns more through repeated interactions.

When using the AI Network Assistant, you can start a new chat or pick up on a chat that took place earlier by visiting the Chat History. You can also delete a previous chat from the Chat History.

You can use the AI Network Assistant to perform these tasks:

  • Network Visibility—Check firmware-managed devices and network information.
  • Event Summary—Request a summary of recent network events to quickly identify issues.
  • Firmware Upgrades—Check firmware files, and upgrade devices.
  • Configuration Procedure—Request a step-by-step configuration procedure and ready-to-run CLI commands for your devices.
  • Product Information—Request information about Allied Telesis products and features.
  • Networking Knowledge—Request information about networking concepts.
Note: Some responses from the AI Network Assistant may include links to relevant documents. Use these links to review the referenced material or confirm the answer in more detail.

AI Network Assistant Licensing

You can chat with the AI Network Assistant without a license. However, some advanced features require an Advanced AI License. These include:

  • Event Summary
  • Firmware Upgrades

These licensed features extend the AI Network Assistant with additional workflow support for reviewing recent event activity and performing firmware upgrade tasks.

To obtain an Advanced AI License, contact your Allied Telesis support representative.

Enable the AI Network Assistant

You can enable the AI Network Assistant from System Management > Optional Features.

  • When you first see the widget, the Enable/Disable toggle will be greyed out.
  • To enable the AI assistant, you must first read the Terms of Service under the widget before you can Enable the feature. Once accepted, you can enable the feature.
  • After you enable the AI assistant, click the new icon in the top right corner to start a chat.

Start a Chat

To start a chat with the AI Network Assistant:

  1. Click the AI Network Assistant icon in the upper right corner of any page.
    The AI Network Assistant appears in a new sidebar that opens on the right side of the page.
  2. Before starting a chat for the first time, you must click the Terms of Service link, read through the terms, and agree to them by clicking I Agree.
  3. In the interface, enter any question using natural language related to your network.
    While the AI Network Assistant is formulating an answer to your question, you can click Stop if you want it to stop processing.
  4. Rate the AI Network Assistant’s response by clicking either the thumbs up or thumbs down icons.
    Rating the response helps the AI Network Assistant to better understand what information you are seeking for future requests.
  5. Continue asking questions about the same subject matter, or start a new chat by clicking New Chat.
