Set Up Bootstrapping

To set up bootstrapping for a Customer’s device, a PartnerAdmin or a PartnerUser that has access to the Customer must perform these steps:

  • Verify the bootstrap setting — By default, bootstrapping is enabled. However, before onboarding a device, the best practice is to verify that bootstrapping is enabled.
  • Provide a bootstrap configuration file — copy and paste a configuration directly into the bootstrap UI, or upload a file to OneConnect.
  • Select the bootstrap release.

To set up bootstrapping for a device:

  1. In the left pane, click Customer Management, then in the customer table that appears, click a customer name, for example, Customer One.
    The customer page appears.
  2. In the customer page, click the Devices tab, then in the devices table that displays, click a device name, for example, Switch1.
    The device page displays.
  3. In the device page, click the Bootstrap Config tab.
    The Bootstrap Settings and Bootstrap Config panes open.
  4. In the Bootstrap Settings pane, verify that Bootstrap Enabled is set to Enabled, and optionally set Verbose Events to Enabled for a greater level of detail in the event log.
  5. To provide a bootstrap configuration using the copy and paste option, copy and paste it into the text box of the Bootstrap Config pane, then click Save.
    Note: OneConnect will automatically add the service cloud-client command to the configuration that you paste into the text box. This command enables the device to connect to a cloud service, which monitors and manages the device.
  6. To provide a bootstrap configuration using the upload option, click Upload in the Bootstrap Config pane, select the file, and click Open.
    The contents of the selected file will appear in the text box.
  7. Select a bootstrap release: in the Bootstrap Settings pane, click the Bootstrap Release edit icon, select a release from the drop-down list, and click Save.
    The releases that appear in the list are approved by Allied Telesis for the device you are setting up.
